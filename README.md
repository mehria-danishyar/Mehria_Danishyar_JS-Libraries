# Explore the World 

A responsive travel/vacation website built using HTML, CSS, and JavaScript.

## JavaScript Libraries Used
1. **AOS (Animate On Scroll)** – for fade-up and scroll animations  
2. **Typed.js** – for the typing effect in the hero section  
3. **ScrollReveal** – for smooth image/card entrance animations  
4. **Lightbox2** – for gallery image popups
